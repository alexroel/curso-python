[![YouTube](https://img.shields.io/badge/YouTube-Ver%20Curso%20Completo-red?style=for-the-badge&logo=youtube)](https://youtu.be/lZOTL4pyYpU)

## 📖 Descripción

Curso completo y gratuito de **Python desde cero**, diseñado para personas sin experiencia previa en programación. A lo largo de más de 5 horas de contenido, aprenderás los fundamentos del lenguaje Python de forma práctica y progresiva: desde instalar tu entorno de desarrollo hasta dominar la Programación Orientada a Objetos y el manejo de archivos. Cada módulo incluye **proyectos prácticos del mundo real** para que consolides lo aprendido, y se integran herramientas de **inteligencia artificial** como apoyo en tu proceso de aprendizaje.

## 📋 Contenido del Curso

### 🎬 Presentación

### 📦 Módulo 1: Introducción y Primeros Pasos

> Configura tu entorno de desarrollo, aprende los conceptos básicos del lenguaje (tipos de datos, variables, entrada/salida) y crea tu primer programa en Python.

- Instalar Python
- Intérprete de Python y Operadores aritméticos
- Tipos de datos básicos
- Variables
- Entrada y conversiones de datos
- Instalación de VSCode
- Crear y Ejecutar primer programa
- 🛠️ [Proyecto Práctico 1: Generador de Nombres para Startups de IA](./hola-mundo/hola.py)
- Mejora el código con inteligencia artificial

---

### 🧠 Módulo 2: Lógica y Estructuras de Datos

> Domina el flujo de control de tus programas con condicionales y bucles, y aprende a organizar información usando listas, diccionarios, tuplas y sets.

- Operadores condicionales y lógicos
- Condicionales (if, elif, else)
- Bucle mientras (While), break y continue
- Listas y métodos de listas
- Bucle Para o For (range, enumerate)
- Diccionarios
- Tuplas y Sets
- 🛠️ [Proyecto Práctico 2: Filtro de Toxicidad para Redes Sociales](./hola-mundo/py-social.py)
- Recomendaciones y uso de IA: Modelos gratuitos en VSCode

---

### ⚙️ Módulo 3: Funciones y Modularidad

> Aprende a escribir código reutilizable con funciones, a tipar tu código con Type Hinting y a organizar proyectos usando módulos y paquetes.

- Funciones integradas
- Creando tus propias Funciones
- Alcance de las variables (Scope)
- Parámetros indefinidos (*args, **kwargs)
- Type Hinting (Tipado estático moderno)
- Módulos y Librerías Estándar
- 🛠️ [Proyecto Práctico 3: Generador de Contraseñas](./genera-password/)
- Creación de Módulos y Paquetes propios

---

### 🏗️ Módulo 4: Programación Orientada a Objetos (POO)

> Descubre el paradigma de la POO: aprende a modelar el mundo real con clases, objetos, herencia, polimorfismo y encapsulación.

- ¿Qué es POO?
- Clases y Objetos
- Atributos y Métodos (self)
- Herencia
- Polimorfismo
- Encapsulación (público, protegido, privado)
- 🛠️ [Proyecto Práctico 4: Registro de Mascotas](./poo/)

---

### 🛡️ Módulo 5: Manejo de Errores y Archivos

> Aprende a crear programas robustos manejando excepciones correctamente y a trabajar con archivos de texto y JSON para persistir datos.

- Tipos de errores (Sintaxis, Lógica, Excepciones)
- Manejo de Excepciones (try, except, finally)
- Excepciones Múltiples
- Generar Excepciones
- Crear Excepciones
- Trabajando con Archivos
- Trabajando PATH y JSON
- 🛠️ [Codigo fuente: Manejo de errores y archivos](./errores-archivos/)

### 👋 Despedida y Siguiente Paso

> ¡Felicidades por completar el curso! 🎉 Ahora tienes las bases sólidas de Python para seguir creciendo como desarrollador.

- 📊 **Ciencia de Datos** — Explora librerías como Pandas, NumPy y Matplotlib para análisis de datos.
- 🤖 **Inteligencia Artificial** — Adéntrate en Machine Learning con Scikit-learn o TensorFlow.
- 🔧 **Automatización** — Automatiza tareas repetitivas con scripts de Python.
- 🧪 **Practica constantemente** — Resuelve retos en plataformas como [LeetCode](https://leetcode.com/), [HackerRank](https://www.hackerrank.com/) o [Codewars](https://www.codewars.com/).
